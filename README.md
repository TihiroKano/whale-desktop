# DSH小鲸鱼余额桌宠（Whale Desktop WdgPet）

![Whale Desktop WdgPet](assets/wdgpet-banner.png)

DeepSeek Harness（DSH）小鲸鱼的**桌面桌宠版**（Electron 桌面应用）：一只常驻桌面的透明悬浮小鲸鱼，实时显示 DeepSeek API **余额**与**今日已用**，带点击互动、拖动吸附与液态玻璃设置窗。

基于原 DSH 网页插件 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)（作者 MeteorNOX）开发；**不装 DSH 也能用**——在设置窗里填一次 API Key 即可。

## 特性

### 记账与显示

- 🐋 **余额**：每 60 秒自动刷新；瞬时网络抖动自动沿用最近余额，不报错、不闪 `--`
- 📊 **今日已用（小鲸鱼记账）**：按余额**下降**自动累计为消费；余额**上升**（充值 / 赠金）单独记录、不会冲掉已有消费；金额按 8 位小数记账、显示保留两位；附 30 天历史
- 💰 **余额变动提醒**：后台检测到余额变化自动弹出气泡，金额数字**滚动动画**过渡到新值
- ⛰️ **峰谷提示**：气泡内显示 DeepSeek 峰谷时段文案（可在设置里调整）
- ⚠️ **失败可见**：余额获取失败时在气泡里显示原因（如「未配置 DEEPSEEK_API_KEY」），点击鲸鱼重试

### 互动

- 🖱️ **拖动 + 吸附**：拖动移动窗口，可停在任意位置；靠近屏幕边缘（30px 内）自动**磁吸贴边**；位置重启后记住
- 🔄 **镜像翻转**：贴左吸附时整体水平镜像（气泡与文字自动翻回，保持正向可读）
- 🧸 **按压 Q 弹**：按压时底部坐标不变、压扁回弹，配合按压 / 松手音效（衔接不叠音）
- 📏 **大小缩放 0.6–2.5×**：滑条 + 1–20 数字档，窗口尺寸随缩放自动变化，气泡不会被裁掉
- 💬 **点击气泡**：点鲸鱼弹出浏览器同款**椭圆思考气泡**（带圆点拖尾弹出动画）——余额页 → 再点看**加权随机台词**（峰谷时段提示 / 吐槽台词 / **摸鲸鱼 gif** / 「哦鲸鲸...」等 6 组）→ 再点关闭；5 秒自动收起
- 📌 **永远浮于最上层**：screen-saver 级置顶 + 定时重新夺顶（托盘可勾选取消「总在最前」）
- 🪟 **跟随任务栏浮动**：任务栏设为「自动隐藏」且鲸鱼贴底停靠时，随任务栏滑出 / 收起一起升降（260ms 平滑过渡，像骑着任务栏）

### 设置窗与托盘

- 🎚️ **液态玻璃设置窗**：右键鲸鱼，或悬停鲸鱼点汉堡按钮打开（16:9 桌面应用式，React 渲染层；Win11 上带系统级亚克力背景模糊）；左侧边栏：通用设置 / 关于
- **通用设置**：大小滑条、音效下拉、**DeepSeek 密钥**（输入 + 保存 / 清除 / 测试，**本机 DPAPI 加密存储**）、平台令牌（折叠）、用量统计（今日 / 本月 + 已用 / 余额进度条）、声音大小、峰谷文案、思考气泡、跟随任务栏浮动
- 🖥️ **托盘菜单**：显示鲸鱼 / 总在最前 / 开机自启（默认关）/ 调试工具 / 退出

### 音效与形象

- 🔊 按压 / 松手音效：内置「小黄鸭」「音效1」两套预置；另有「海浪 / 风铃 / 雨声」三个待素材占位（置灰）
- 🐳 小鲸鱼形象：贴图角色（气泡由代码绘制），含备用整图与表情素材

### 凭据

- 🔑 **不装 DSH 也能用**：在设置窗里填一次 API Key 即可显示余额。解析优先级（高 → 低）：
  1. **设置窗手动保存的 Token**（`.dshw-credentials.json`，Windows DPAPI 加密；可随时清除、自动回落）
  2. 环境变量 `DEEPSEEK_API_KEY`
  3. DSH 凭据文件 `~/.dsh/.credentials.yaml` 的 `refs:` 段
- `DEEPSEEK_PLATFORM_TOKEN`（可选，「实时·令牌」模式用）：同样可在设置窗里填；取值：在 platform.deepseek.com 打开 DevTools，从 usage 请求的 `Authorization: Bearer eyJ...` 头里复制

## 内测版新增（V1.0.1beta）

> 以下功能已在测试版中实现并完成实机验证，将在后续版本（V1.0.1）发布时包含；当前仓库中的程序文件为 V1.0.0。

- 🎲 **特殊交互彩蛋**（设置页新增第 6 项「特殊交互」，默认开启）：连续点击鲸鱼累计 **10–15 次**（相邻间隔超过 1.5 秒则重新计数）后掷一次判定——**30% 真随机**（crypto）命中后随机触发一个效果：
  - **效果 1 · 自毁**：鲸鱼逐级闪烁放大到 2.5×（每次闪烁配一声鸭子叫），涨满后弹出**液态玻璃「程序已自毁」提示窗**，点「确定」退出程序
  - **效果 2 · 逃跑**：按鲸鱼所在位置自动选方向，平移出屏幕后消失（全程播放「杂鱼杂鱼」音频）；托盘「显示鲸鱼」可唤回，原位置不变
  - 开关关闭后连点不再触发；效果进行期间鲸鱼不接受拖动等交互
- 🔊 **音效新增「杂鱼杂鱼」**：音效下拉新增该选项
- 🧊 **玻璃背景刷新链重写（"隐形拍照"）**：修复发布版「关掉白底窗口露出壁纸后玻璃停留白色」的问题——抓帧时窗口对屏幕捕获隐身、用户全程可见；窗口聚焦期间也能刷新，可见变化 **1–4 秒**内跟上，完全被设置窗盖住的变化 **4–6 秒**兜底覆盖；不再有抓帧闪烁
- 🗂️ **设置页右列重排**：声音 → 音效 → 峰谷文案 → 思考气泡 → 跟随任务栏浮动 → 特殊交互
- 🐞 **修复报错**：设置窗关闭时 `desktop-backdrop.js` 抛出的 `win is not defined`（该报错会连累同一关闭事件上的后续处理）

## 安装与运行

- **方式 1：安装包**——运行 `whale-desktopV1.0.0-setup.exe` 安装后，双击桌面「小鲸鱼余额挂件」快捷方式。
- **方式 2：从本仓库本地运行（开发）**——

  ```bash
  cd whale-desktop
  npm install
  npm start
  ```

  需要 Node.js 环境；首次安装依赖会下载 Electron。

**退出**：系统托盘 → 右键鲸鱼图标 → 「退出鲸鱼」。

## 数据文件（均在应用目录）

| 文件 | 用途 |
| :--- | :--- |
| `.dshw-usage.json` | 今日已用记账 + 30 天历史 |
| `.dshw-size.json` | 外观与开关（缩放 / 音量 / 用量模式 / 峰谷文案等） |
| `.dshw-credentials.json` | 设置窗保存的 Token（DPAPI 加密，不可加密时明文兜底） |
| `.dshw-window.json` | 窗口位置记忆 |
| `renderer.log` | 运行日志（超 1MB 自动轮转为 `.old`） |

## 常见问题

- **余额不显示 / 显示 `--`**：右键鲸鱼 → 设置 → 填入 DeepSeek API Key 并点「测试」。
- **鲸鱼被动画壁纸盖住**：若与 Wallpaper Engine 等动画壁纸互相遮挡，请在 Wallpaper Engine 里关闭「窗口置顶（always on top）」。
- **找不到退出 / 设置入口**：退出在系统托盘图标右键；设置是右键鲸鱼（或悬停鲸鱼点汉堡按钮）。

## 已知问题

- **玻璃背景刷新延迟（发布版 V1.0.0）**：关闭白底应用窗口、露出壁纸后，玻璃背景可能长时间停留旧画面，切换焦点或桌面再有变化才自愈 —— **内测版已修复（见上节）**
- **抓帧瞬间窗口闪烁（发布版 V1.0.0）**：玻璃背景抓帧时设置窗短暂消失（每次约 0.3–0.8 秒），快速切换焦点时肉眼可见「一跳一跳」 —— **内测版已改为隐形拍照，不再闪烁**
- **内测版刷新上限**：完全被设置窗盖住的桌面变化由 6 秒兜底覆盖（实测 4–6 秒）；这是保护性设计，不是无限延迟
- **Windows 平台**：依赖 Windows 的 DPAPI 凭据加密与系统级窗口特效（目前仅在 Windows 11 实机验证）
